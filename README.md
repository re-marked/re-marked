> Full-stack engineer focused on **AI agent systems** — I design multi-agent architectures and build the full-stack web and desktop products they run inside. Mostly **TypeScript**, with **Rust** and **Go** underneath.

### What I do

- 🧠 **Agent architecture** — multi-agent systems, orchestration, and persistent AI identity & memory
- 🌐 **Full-stack web** — Next.js · React · Tailwind · Postgres/Supabase, from prototype to production
- 🖥️ **Local-first desktop apps** — Tauri + Rust, offline-first, your data stays on your machine
- ⚙️ **Backends & tooling** — Go services, CLI tools, and the occasional from-scratch terminal UI ([yokai](https://github.com/re-marked/yokai))
